# Tic-Tac-Toe

A console-based implementation of the classic **Tic-Tac-Toe** game developed in Java.

The application allows a human player to compete against a computer opponent through a text-based interface.

---

## Features

- Interactive console gameplay
- Human vs Computer mode
- Random computer move generation
- Input validation
- Win, lose and draw detection
- Board visualization after every move
- Invalid move handling

---

## Gameplay

Players enter their moves using board coordinates.

Example:

```
Player Move (X):

A1
```

The computer automatically generates its move and updates the board until one player wins or the game ends in a draw.
