# Project Management Case Study

A project management case study developed using planning and modeling techniques as part of a university **Project Management** course.

This repository demonstrates the complete planning and management lifecycle of a software project, including business process modeling, project scheduling, work decomposition, and project documentation.

---

## Project Overview

The project covers multiple aspects of project planning and execution, including:

- Business Process Modeling (BPMN 2.0)
- Work Breakdown Structure (WBS)
- Gantt Chart Scheduling
- DAE Diagram
- Project Baseline and Interim Planning

The BPMN model illustrates the collaboration between the **Project Manager (PM)**, **Financial Manager (FM)**, and the **Project Team**, representing the project's workflow from planning to execution.
