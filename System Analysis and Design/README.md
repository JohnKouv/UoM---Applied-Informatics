# CarOps Information System
This repository contains the complete deliverables of our **System Analysis and Design** university project.

Our team analyzed the business processes of a fictional vehicle repair workshop called **CarOps**, designed an improved information system, modeled its architecture using UML, and implemented a Java prototype based on the final design.

The project follows the complete **Software Development Life Cycle (SDLC)**, covering business analysis, system design, UML modeling, project management, and implementation.

## Project Overview

The objective of this project was to redesign the daily operations of the CarOps vehicle workshop by replacing its manual workflow with a structured Information System.

The proposed system improves:

- Appointment scheduling
- Customer and vehicle management
- Repair process organization
- Work assignment to mechanics
- Repair cost estimation
- Payment management
- Repair history tracking
- Overall business efficiency

Throughout the project we identified the existing business problems (AS-IS), designed improved workflows (TO-BE), gathered requirements, modeled the system using UML, and finally implemented a working Java prototype.
